# העלאת GLoW לאוויר

המטרה: כתובת אינטרנט קבועה שנכנסים אליה מכל דפדפן — מחשב, טלפון, טאבלט.
בלי התקנה, בלי חנות אפליקציות. שולחים לינק, וזהו.

## הדרך המהירה — כפתור אחד

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fbarakliver%2Fglow-&project-name=glow&repository-name=glow)

הכפתור פותח את Vercel עם המאגר כבר טעון. מתחברים עם GitHub, לוחצים
**Deploy**, ותוך כדקה מקבלים כתובת כמו `https://glow.vercel.app`.

זה מספיק כדי **לראות ולהראות** את האפליקציה. כל המסכים עובדים עם נתוני
הדגמה מלאים: שבוע שיעורים, מאמנים, מתאמנים, אימונים וטיימר.

**מגבלה אחת, וחשוב להכיר אותה:** בלי מסד נתונים הנתונים נשמרים בזיכרון
השרת בלבד. השרת מתאפס מדי פעם, ולכן רישום לשיעור עלול להיעלם. באפליקציה
מופיעה על כך הודעה גלויה, כדי שאף אחד לא יתבלבל.

לשימוש אמיתי עם חברים — ממשיכים לשלב הבא. זה לוקח עוד כחמש דקות.

## חיבור מסד נתונים (Supabase) — לשימוש אמיתי

### 1. יצירת פרויקט

נכנסים ל-[supabase.com](https://supabase.com), **New Project**. התוכנית
החינמית מספיקה בהחלט למועדון פרטי.

### 2. העתקת המפתחות

**Project Settings → API**, ומעתיקים שלושה ערכים:

| בדשבורד (Project Settings → API Keys) | לאן זה הולך |
| --- | --- |
| כתובת הפרויקט (General → Project ID) | `NEXT_PUBLIC_SUPABASE_URL` |
| **Publishable key** (`sb_publishable_...`) | `NEXT_PUBLIC_SUPABASE_ANON_KEY` |
| **Secret key** (`sb_secret_...`) | `SUPABASE_SERVICE_ROLE_KEY` |

בפרויקטים ותיקים יותר המפתחות נקראים `anon` ו-`service_role` ונמצאים בלשונית
**Legacy**. שניהם נתמכים — שם משתנה הסביבה לא משתנה.

`service_role` הוא מפתח רגיש. הוא נשאר בשרת בלבד — לעולם לא עם הקידומת
`NEXT_PUBLIC_`.

### 3. יצירת הטבלאות — הדבקה אחת

פותחים **SQL Editor** בדשבורד, לוחצים **New query**, ומדביקים את כל התוכן
של הקובץ **`supabase/setup.sql`**. לוחצים **Run**.

זהו. הקובץ יוצר הכול בבת אחת:

- כל הטבלאות, האינדקסים והאילוצים
- פונקציות ההרשמה, הביטול וקידום מרשימת ההמתנה
- הרשאות אבטחה (RLS) על כל טבלה
- תוכן התחלתי: 20 תרגילים עם הוראות ודגשי בטיחות, 6 תבניות אימון ו-3
  תבניות טיימר

**בלי** אנשים או שיעורים מדומים — את הלוח אתה בונה מתוך האפליקציה.

> רוצה גם נתוני הדגמה (8 משתמשים, שבוע שיעורים, רישומים)? הרץ אחר כך גם את
> `supabase/seed.sql`. מתאים להתנסות, לא למועדון אמיתי.

**לבדיקה שהכול נחת:** הדבק והרץ את `supabase/verify-setup.sql`. מתקבלת טבלה
עם תשע שורות, וכולן צריכות להיות "תקין".

מי שמעדיף שורת פקודה:

```bash
npx supabase link --project-ref <project-ref>
npx supabase db push
```

הקובץ `setup.sql` נוצר אוטומטית מהמיגרציות (`npm run build:setup-sql`), ולכן
הוא תמיד מסונכרן איתן.

### 4. הפעלת כניסה במייל

**Authentication → Providers → Email** → מפעילים Magic Link.

### 5. הזנת המשתנים ב-Vercel

בפרויקט ב-Vercel: **Settings → Environment Variables**.

| משתנה | ערך |
| --- | --- |
| `NEXT_PUBLIC_APP_URL` | הכתובת שקיבלת, לדוגמה `https://glow.vercel.app` |
| `NEXT_PUBLIC_SUPABASE_URL` | מ-Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | מ-Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | מ-Supabase |
| `CRON_SECRET` | מחרוזת אקראית כלשהי |

אחרי השמירה לוחצים **Redeploy**. הודעת ההדגמה נעלמת מעצמה.

### 6. סגירת מעגל ההתחברות

חוזרים ל-Supabase → **Authentication → URL Configuration** → מוסיפים
ל-*Redirect URLs*:

```
https://<הכתובת-שלך>/auth/callback
```

### 7. הגדרת עצמך כבעלים

נכנסים לאפליקציה עם המייל שלך, ואז ב-SQL Editor:

```sql
update public.memberships set role = 'owner'
where profile_id = (select id from public.profiles where email = 'you@example.com');
```

מכאן יש לך גישה לאזור הניהול המלא.

- **מחשב** — השבוע כולו מוצג יחד, ואזור הניהול נפרש לרוחב.

אין שתי גרסאות ואין מה לתחזק פעמיים.

## הזמנת חברים

באזור הניהול: **הזמנות → הזמנה חדשה**. מקבלים קישור וקוד QR, ואפשר לשתף
בוואטסאפ ישירות מהמסך.

אפשר להגדיר לכל הזמנה תאריך תפוגה ומספר שימושים מרבי, ולבטל אותה בכל רגע.

מי שפותח את הקישור רואה את הלוח המפורסם — שם שיעור, שעה, מאמן, מיקום
ומספר מקומות פנויים. שמות המתאמנים, מספרי הטלפון ונתוני האימון לא נחשפים
בשום שלב. כדי להירשם לשיעור צריך להתחבר.

## תוספת אופציונלית: התקנה כאפליקציה

לא חובה, והאתר עובד מצוין בלעדיה. מי שרוצה אייקון במסך הבית ופתיחה במסך
מלא, יכול להתקין מתוך האפליקציה: **עוד → האפליקציה במכשיר שלך**.

- **אנדרואיד וכרום במחשב** — לחיצה אחת.
- **אייפון** — מתוך Safari: שיתוף → הוספה למסך הבית.

אחרי התקנה הטיימר והאימון הפעיל ממשיכים לעבוד גם בלי קליטה, וסטים
שנרשמו מסתנכרנים כשהחיבור חוזר.

## שאלות נפוצות

**כמה זה עולה?**
כלום. Vercel ו-Supabase נותנות תוכנית חינמית שמספיקה בקלות למועדון פרטי.

**האם צריך לקנות דומיין?**
לא. מקבלים כתובת `vercel.app` בחינם. אם בהמשך תרצה דומיין משלך, מחברים
אותו ב-Vercel תחת **Settings → Domains**.

**איך מעדכנים את האפליקציה?**
כל דחיפה ל-GitHub מפעילה פריסה אוטומטית. המשתמשים מקבלים את הגרסה החדשה
בכניסה הבאה, בלי לעשות כלום.

**מה קורה אם משהו נשבר?**
ב-Vercel יש **Deployments** עם היסטוריה מלאה, ואפשר לחזור לגרסה קודמת
בלחיצה על **Promote to Production**.

## תזכורות אוטומטיות

`vercel.json` מגדיר משימה יומית שרצה ב-08:00 (שעון ישראל) ושולחת תזכורת לכל
מי שרשום לשיעור ב-24 השעות הקרובות.

התוכנית החינמית של Vercel מאפשרת הרצה אחת ביום בלבד, ולכן זו התדירות. מי
שעובר ל-Pro יכול לשנות ב-`vercel.json` ל-`"schedule": "0 * * * *"` עם
`minutes=120`, וכך התזכורת תישלח שעתיים לפני כל שיעור.

כדי שהמשימה תרוץ צריך להגדיר ב-Vercel משתנה סביבה בשם `CRON_SECRET` עם
מחרוזת אקראית כלשהי.
