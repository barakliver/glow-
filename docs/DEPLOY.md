# העלאת GLoW לאוויר והתקנה כאפליקציה

מדריך מקוצר בעברית. אחריו האפליקציה תהיה זמינה בכתובת קבועה, תיפתח במחשב
כאתר רגיל, ותותקן בטלפון כאפליקציה עם אייקון במסך הבית.

---

## למה צריך להעלות לאוויר

התקנה של אפליקציה בטלפון דורשת כתובת אינטרנט עם **HTTPS**. כל עוד האפליקציה
רצה רק במחשב שלך (`localhost`) אי אפשר להתקין אותה בטלפון.

---

## שלב 1 · חיבור Supabase (חובה לשימוש אמיתי)

בלי Supabase האפליקציה עובדת ב**מצב הדגמה** — הנתונים נשמרים בזיכרון השרת
בלבד. זה מצוין להתנסות, אבל בשרת אמיתי הזיכרון מתאפס, ורישומים ואימונים לא
יישמרו. לפני שמזמינים חברים אמיתיים צריך מסד נתונים.

1. פותחים חשבון ב-[supabase.com](https://supabase.com) ויוצרים פרויקט.
   התוכנית החינמית מספיקה למועדון פרטי.
2. מעתיקים מ-**Project Settings → API** את שלושת הערכים:
   `Project URL`, `anon public`, `service_role`.
3. מריצים את המיגרציות. מתוך תיקיית הפרויקט:

   ```bash
   npx supabase link --project-ref <project-ref>
   npx supabase db push
   ```

   לחלופין: פותחים את **SQL Editor** בדשבורד ומדביקים לפי הסדר את שלושת
   הקבצים מתוך `supabase/migrations/`.

4. ב-**Authentication → Providers → Email** מפעילים קישורי כניסה (Magic Link).

## שלב 2 · העלאה ל-Vercel

Vercel היא הדרך הקצרה ביותר, והיא חינמית לשימוש פרטי.

1. מעלים את הקוד ל-GitHub (כבר נמצא שם, בענף `claude/magical-volta-ynuw6g`).
2. נכנסים ל-[vercel.com](https://vercel.com), **Add New → Project**, ובוחרים
   את המאגר. Vercel מזהה Next.js לבד — אין מה להגדיר.
3. ב-**Environment Variables** מוסיפים:

   | משתנה | ערך |
   | --- | --- |
   | `NEXT_PUBLIC_APP_URL` | הכתובת הסופית, לדוגמה `https://glow.vercel.app` |
   | `NEXT_PUBLIC_SUPABASE_URL` | ה-Project URL מ-Supabase |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | מפתח `anon public` |
   | `SUPABASE_SERVICE_ROLE_KEY` | מפתח `service_role` — **לעולם לא עם קידומת `NEXT_PUBLIC_`** |
   | `CRON_SECRET` | מחרוזת אקראית כלשהי, לתזכורות |

4. לוחצים **Deploy**. הבנייה לוקחת כדקה.

5. חוזרים ל-Supabase, **Authentication → URL Configuration**, ומוסיפים ל-
   *Redirect URLs* את `https://<הכתובת-שלך>/auth/callback`.

6. נכנסים לאפליקציה בפעם הראשונה עם המייל שלך, ואז ב-SQL Editor מגדירים את
   עצמך כבעלים:

   ```sql
   update public.memberships set role = 'owner'
   where profile_id = (select id from public.profiles where email = 'you@example.com');
   ```

`vercel.json` שבפרויקט כבר מגדיר את משימת התזכורות השעתית ואת הכותרות של
ה-service worker — אין צורך לגעת בו.

## שלב 3 · שימוש במחשב

פשוט נכנסים לכתובת בדפדפן. הפריסה מתרחבת אוטומטית למסך רחב: הלוח השבועי
מוצג כשבוע מלא במקום יום אחד, ואזור הניהול נפרש לרוחב.

בכרום אפשר גם להתקין את האפליקציה במחשב — אייקון ההתקנה מופיע בצד ימין של
שורת הכתובת, ו-GLoW נפתח בחלון נפרד בלי סרגלי דפדפן.

---

## שלב 4 · התקנה בטלפון

באפליקציה עצמה: **עוד → האפליקציה במכשיר שלך → התקנת GLoW כאפליקציה**.

### אנדרואיד (Chrome)

לחיצה אחת על הכפתור, ואישור. האייקון מופיע במסך הבית.

### אייפון (Safari)

באייפון אפל לא מאפשרת התקנה בלחיצה אחת, ולכן הכפתור פותח הסבר קצר:

1. פותחים את הכתובת ב-**Safari** (לא בכרום — באייפון רק Safari יודע להתקין).
2. לוחצים על אייקון **השיתוף** בתחתית המסך.
3. גוללים ובוחרים **"הוספה למסך הבית"** ומאשרים.

אחרי ההתקנה GLoW נפתח במסך מלא, בלי סרגל הדפדפן, בדיוק כמו אפליקציה מהחנות.

---

## מה עובד בלי אינטרנט

אחרי ההתקנה, גם כשאין קליטה:

- **טיימר האינטרוולים** עובד במלואו, כולל צלילים ורטט.
- **אימון פעיל** ממשיך לרוץ. כל סט שנרשם נשמר במכשיר, ומסונכרן אוטומטית
  ברגע שהחיבור חוזר. מופיעה הודעה כמה רשומות ממתינות לסנכרון.
- מסכים שכבר נטענו נשמרים במטמון ונפתחים גם במצב לא מקוון.

רישום לשיעור דורש חיבור, כי הוא חייב לבדוק תפוסה מול השרת.

## שאלות נפוצות

**האם צריך להעלות לחנות האפליקציות?**
לא. GLoW היא Progressive Web App — מותקנת ישירות מהדפדפן, בלי App Store,
בלי Google Play, בלי דמי מפתח ובלי אישורים.

**איך מזמינים חברים?**
באזור הניהול: **הזמנות → הזמנה חדשה**. מקבלים קישור וקוד QR, אפשר לשתף
בוואטסאפ. אפשר להגדיר תאריך תפוגה ומספר שימושים, ולבטל בכל רגע.

**האם המוזמנים רואים את פרטי המתאמנים?**
לא. דף ההזמנה הציבורי מציג רק שם שיעור, שעה, מאמן, מיקום ומספר מקומות
פנויים. שמות, טלפונים ונתוני אימון לא נחשפים בשום שלב.

**מה קורה כשמעדכנים את האפליקציה?**
הגרסה החדשה נטענת אוטומטית בכניסה הבאה. אין צורך להתקין מחדש.
